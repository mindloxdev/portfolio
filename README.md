# Adnan Rasool | Medical Billing and RCM Portfolio

A one-page portfolio site for medical billing and revenue cycle management services. It uses plain HTML, CSS and JavaScript, with no build step.

## Files

- `index.html`: the page
- `styles.css`: styles
- `script.js`: mobile menu, scroll animations, footer year, contact links
- `favicon.svg`: site icon

## Edit your contact details

Open `index.html` and find the block marked `CONTACT DETAILS (edit or remove here)` near the top of `<body>`. Change the email and phone there. The same values also appear in the plain `mailto:` and `tel:` links (search the file for `iidnan@gmail.com` and `8172564378`), so update those too for visitors with JavaScript turned off.

## Publish on GitHub Pages

1. Sign in at https://github.com and click **New repository**.
2. Name it. Use `yourusername.github.io` for a URL like `https://yourusername.github.io`, or any other name (for example `portfolio`) for `https://yourusername.github.io/portfolio`.
3. Set it to **Public** and click **Create repository**.
4. Click **uploading an existing file**, drag in `index.html`, `styles.css`, `script.js`, `favicon.svg` and `README.md`, then click **Commit changes**. `index.html` must sit at the top level of the repo, not inside a folder.
5. Open **Settings > Pages**.
6. Under **Build and deployment**, set **Source** to **Deploy from a branch**, set the branch to **main** and the folder to **/ (root)**, then click **Save**.
7. Wait one to two minutes and refresh the page. The live URL appears at the top of **Settings > Pages** ("Your site is live at ...").
8. Add that URL to your Upwork profile under **Portfolio** or in your profile overview.

## Update the site later

Edit a file on GitHub (pencil icon) or upload a new version, then commit. GitHub Pages redeploys automatically within a minute or two.
